# A 题简报：药材的烘干问题（热质耦合、非线性、移动边界）

## 1. 题目要求与交付映射

## 2. 控制方程（一维径向，圆柱）

长径比 L/R = 12.5，轴向传热与传质对中截面的影响可忽略（应在验证一节用二维轴对称算例量化端部效应）。

- 能量：ρ c_p ∂T/∂t = (1/r) ∂/∂r ( k r ∂T/∂r )
- 水分：∂C/∂t = (1/r) ∂/∂r ( D r ∂C/∂r )
- 中心对称：∂T/∂r = ∂C/∂r = 0 (r=0)
- 表面（题给参数的直接解释）：−k ∂T/∂r = h (T − T_air(t))；−D ∂C/∂r = h_m (C − C_air(t))
- 初值：T=28 °C，C=2.55 kg/kg。附件 1 线性插值；14400 s 之后按最后一组值（≈50 °C，≈0.05 kg/kg）恒定（"恒温干燥阶段"），MDR 记录。

附录公式（注意指数形式）：
- 附录 2：ρ=820，c_p=2600，k=0.36，h=25，h_m=8e-7，D = 7×10⁻⁹·exp(−0.89/C)
- 附录 3：ρ=650+128C，c_p=1450+2736·C/(C+1)，k=0.21+0.38·C/(C+1)，D = 2.4×10⁻³·exp(−0.45/C)·exp(−3850/T)，T 为 K
- 附录 4：ρ=760+90C，c_p=1850+2150·C/(C+1)，k=0.12+0.20·C/(C+1)，D = 4.2×10⁻⁴·exp(−0.30/C)·exp(−3850/T)

必须在论文中明确：题给"对流传质系数 × (C_s − C_air)"把空气含湿量与药材干基含水率放在同一量纲下比较，是题目设定的简化；世界级处理方式是在"模型评价"中讨论平衡含水率/等温吸附曲线与表面蒸发潜热耦合的影响，并给出灵敏度（但主结果必须按题给参数与边界条件计算）。

## 3. 数值方法（必须满足）

1. 有限体积（径向控制体，r 加权）保证守恒；空间二阶；非线性系数在界面用调和平均/算术平均并说明。
2. 时间积分：全隐式（BDF/Radau 或 Crank–Nicolson + Newton/Picard），步长自适应，输出在所需时间点精确采样（不要用最近邻）。
3. 网格：Δr ≤ 0.1 cm 的整数细分（0.1/2^k），输出点与网格节点重合，避免插值误差；给出 Δr、Δt 收敛表与观测阶数。
4. 验证：常物性圆柱对流边界的解析级数解（贝塞尔函数，特征值满足 Bi·J0(λ)=λ·J1(λ)）对照，误差 < 1e-4 量级；水分总量变化 = 表面通量时间积分（守恒检查）；解无越界（最大值原理）。
5. 问题 4 移动边界：Landau 变换 ξ=r/R(t)，方程增加对流项 −ξ (Ṙ/R) ∂/∂ξ；R(t) 由附件 2 单调插值（PCHIP），Ṙ 由插值导数给出；退化检验：R≡2 cm 时与问题 3 方案一致。干物质守恒的处理方式写进 MDR。
6. 烘干结束判定：max_r C(r,t) < 0.15 的首个时刻（通常在中心），按小时给出并说明分辨率（60 s）。

## 4. 论文必须包含

- 假设列表与依据；符号表；一维化的量化论证。
- 四个问题的模型、离散格式、算法、结果表（题定格式）、剖面/时程图（温度与水分浓度随 r、t）。
- 验证：解析解对照、收敛表、守恒误差、时间步无关性、二维端部效应估计。
- 灵敏度：h、h_m、D 前因子、C_air 平台值、R(t) 的 ±20%；烘干时间的弹性。
- 局限：平衡含水率、蒸发潜热、各向异性、收缩各向同性假设。

## 5. 风险与对策

- 指数项 exp(−0.89/C) 在 C→0 时极小，D 变得极小导致刚性：使用隐式方法并限制 C 的下界（物理上 C≥0）。
- result2 的时间范围解释：默认 3 h（与表 3/4 一致），在 MDR 中记录，并说明全过程数据由 result3 提供。
- 计算量：1 s 输出 × 21 列很小；收敛研究用更细网格但不必输出。
