# MDR-0004 数值方法：径向有限体积 + 自适应全隐式时间积分

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 1–4

## 问题
控制方程是强非线性、刚性的热质耦合抛物方程：D 随 C 呈 exp(−a/C) 变化（干燥后期表面 D 可小至 10⁻¹² m²/s，比初始值小三个数量级），温度方程的扩散时间尺度（分钟）与水分（天）相差三个数量级。要求输出在 0.1 cm 网格与 1 s/60 s 时间点上精确采样并保留四位小数。

## 备选方案
1. 节点型有限体积（节点 r_i = iΔr，控制体 [r_{i−1/2}, r_{i+1/2}]，r 加权）+ scipy `solve_ivp` 的变阶 BDF（全隐式、步长自适应、稀疏雅可比）。
2. 有限差分显式格式：稳定性要求 Δt ≤ Δr²/(2α)，最细网格下需数百万步，且对刚性变化不鲁棒。
3. 自编 Crank–Nicolson + Newton：可行，但需自行实现步长控制与误差估计，实现风险高于成熟库。

## 决策与理由
采用方案 1：
- 空间：节点型 FV 保证离散守恒，输出点（0.1 cm 整数细分 Δr = 0.1/2^k cm）与节点重合，无插值；中心节点用半控制体（体积 Δr²/8），表面节点半控制体上直接施加 Robin 通量，整体二阶精度。
- 界面系数：默认取**界面状态法** D_{i+1/2} = D((C_i+C_{i+1})/2, (T_i+T_{i+1})/2)（对指数型 D 最接近 Kirchhoff 精确界面通量），并与算术平均、调和平均对比（离散化敏感性表）。
- 时间：BDF（最高 5 阶）自适应步长，rtol=1e-7、atol=1e-9，块三对角稀疏雅可比（有限差分分组）；输出时刻由 BDF 的稠密插值精确采样；用 Radau 与更严格容差交叉检验。
- 生产网格：Δr = 0.0125 cm（k=3，161 节点），由收敛表确定，使表格量的离散误差远小于 5×10⁻⁵（四位小数）。
- C 的下界：仅在评估 D 时用 max(C, 10⁻⁶) 避免除零；不修改状态。

## 对结果的影响与验证
`convergence` 阶段给出 Δr = 0.1/2^k（k=0…4）的收敛表与观测阶数（应≈2）、时间容差无关性；`verification` 阶段给出常物性 Robin 圆柱的贝塞尔级数解对照（误差 <10⁻⁴）。复杂度：每步 O(N)（带状 LU），总代价 O(N·N_steps)。

## 补充（2026-09-12，运行 20260912-034737 后）
- 自收敛表显示温度误差在 Δr ≤ 0.025 cm 后停滞于约 2×10⁻⁴，而常物性恒定环境算例对贝塞尔级数解干净地二阶收敛（1.6×10⁻⁴ → 1.0×10⁻⁵ → 2.6×10⁻⁶）。原因是烘房温度按 60 s 样本线性插值，斜率在每个样本处跳变，多步法跨过折点时的误差不受容差控制。处理：时间积分在每个数据折点（附件 1 的全部样本时刻与切换到平台的时刻；附件 2 的 PCHIP 节点）处重启（`integrate_piecewise`），段内强迫项光滑；二维校验程序同样处理。
- 生产容差收紧为 rtol=1e-9、atol=1e-11（代价约 2.7 倍右端项调用，问题 3 仍在 20 s 内）。
