# 药材的烘干问题（CUMCM 2026 A 题）

本仓库是 2026 年高教社杯全国大学生数学建模竞赛 A 题的完整研究工程：原始题目与附件、云端流水线、模型与求解程序、测试、论文源码与交付物。所有数据处理、计算、绘图、排版与打包均在 Modal 云端按固定镜像执行；本地只做文本编辑、Git 操作、任务提交、下载与散列校验。

## 内容

- `docs/ENGINEERING_STANDARD.md`：工程规范（阶段/清单/契约/门禁/发布）。
- `docs/MODELING_STANDARD.md`：建模与写作标准、审稿清单。
- `docs/problem_brief.md`：题目分析与建模路线。
- `docs/mdr/`：建模决策记录；`docs/adr/`：工程决策记录。
- `pipelines/a/`：本题的全部模型、求解与结果生成程序。
- `manuscript/`：论文源码；`releases/<tag>/`：论文 PDF、结果工作簿、支撑材料与 SHA-256 清单。

## 复现

```bash
python3 tools/cli.py provision
python3 tools/cli.py run ingest,validate --new-run
# 科学阶段见 docs/RUNBOOK.md 与 pipelines/a/stages.py
python3 tools/cli.py run lint,test,paper,qa,package,release
python3 tools/cli.py release --version <tag>
```


## 结果概要

方法：一维径向热质耦合方程（圆柱中截面），节点型有限体积（Δr = 0.003125 cm，641 节点，节点与 0.1 cm 输出网格重合）+ 自适应 BDF（rtol 1e-9，在烘房数据折点处重启），输出时刻由稠密插值精确采样；问题 4 采用干物质守恒的拉格朗日 Landau 坐标处理附件 2 的半径收缩（欧拉写法与固定半径作为对照）。建模决策见 `docs/mdr/`，数值与图表说明见 `docs/RESULTS.md`。

| 问题 | 关键结果（均来自云端 run，见 `numbers.json`） |
|---|---|
| 1 | 30 min 末中心/表面温度 33.58/36.79 °C（烘房 41.51 °C）；表面水分 1.51 kg/kg，中心仍为 2.55；30 min 失水 10.1% |
| 2 | 3 h 末温度已与烘房平衡（49.85–49.97 °C）；水分中心 1.77、表面 1.01 kg/kg，失水 45.8% |
| 3 | 各处水分低于 0.15 kg/kg 的烘干时间 57.48 h（60 s 分辨率 57.4833 h；网格收敛到 ±0.3 min） |
| 4 | 考虑半径收缩（2.000→1.198 cm）：51.09 h；欧拉写法 52.65 h（+3.1%）；若半径不变则 129.85 h |

检验：常物性 Robin 圆柱贝塞尔级数解对照误差 1×10⁻⁵（观测阶 2.00）；六级网格自收敛观测阶 2.0–2.3；离散水分/能量守恒相对残差 ~10⁻¹⁵（积分器内累积边界通量）；Radau 与更严格容差交叉检验差异 <10⁻⁸；独立二维轴对称程序端面绝热时与一维解差 6×10⁻⁹，端面对流时端部效应使烘干时间仅变化 −0.004%。灵敏度（烘干时间弹性）：烘房平台温度 −1.60，收缩幅度 −1.13，扩散系数前因子 −0.89，传质系数 −0.11，换热系数 ≈0，烘房湿度 +0.02。

局限：平衡含水率/等温吸附与蒸发潜热未建模（题给线性表面条件）；收缩假定各向同性均匀；h、h_m 恒定；14400 s 之后烘房条件为平台外推。
