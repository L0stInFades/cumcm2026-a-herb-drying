# 药材的烘干问题（CUMCM 2026 A 题）

本仓库是 2026 年高教社杯全国大学生数学建模竞赛 A 题的完整研究工程：原始题目与附件、云端流水线、模型与求解程序、测试、论文源码与交付物。所有数据处理、计算、绘图、排版与打包均在 Modal 云端按固定镜像执行；本地只做文本编辑、Git 操作、任务提交、下载与散列校验。

## 内容

- `docs/ENGINEERING_STANDARD.md`：工程规范（阶段/清单/契约/门禁/发布）。
- `docs/MODELING_STANDARD.md`：建模与写作标准、审稿清单。
- `docs/problem_brief.md`：题目分析与建模路线。
- `docs/mdr/`：建模决策记录；`docs/adr/`：工程决策记录。
- `pipelines/a/`：本题的全部模型、求解与结果生成程序。
- `manuscript/`：论文源码；`releases/<tag>/`：论文 PDF、结果工作簿、支撑材料与 SHA-256 清单。

## 复现

```bash
python3 tools/cli.py provision
python3 tools/cli.py run ingest,validate --new-run
# 科学阶段见 docs/RUNBOOK.md 与 pipelines/a/stages.py

```


## 结果概要

**方法。** 由能量与水分守恒律导出圆柱内一维径向的热质耦合抛物方程组，中心取对称条件、表面取题给参数确定的 Robin 条件，烘房状态由附件 1 逐点插值、\SI{14400}{s} 之后取恒温阶段平台值。四个问题共用同一套模型与程序，只更换物性公式、时间范围与边界是否移动。数值上采用顶点型有限体积（Δr = 0.003125 cm，641 节点，与 0.1 cm 输出网格重合）配合稀疏雅可比的自适应 BDF（rtol 1e-9 / atol 1e-11，在每个数据折点重启），烘干结束时刻由事件求根精确定位；问题 4 在干物质守恒的 Landau 物质坐标下求解收缩域问题。建模决策见 `docs/mdr/`，审稿意见的逐条处理见 `docs/REVIEW_RESPONSE.md`，数值与图表说明见 `docs/RESULTS.md`。

| 问题 | 关键结果（全部来自同一次云端 run 的 `numbers.json`） |
|---|---|
| 1 | 1800 s 时中心/表面温度 33.5753 / 36.7856 °C（同时刻烘房 41.513 °C）；水分中心仍为 2.5500、r = 1 cm 处 2.5383、表面 1.5102 kg/kg；30 min 失水 10.06% |
| 2 | 3 h 时中心/表面温度 49.8495 / 49.9664 °C（已近等温）；水分中心 1.7662、表面 1.0081 kg/kg，失水 45.78% |
| 3 | 各处水分低于 0.15 kg/kg 的烘干时间 **57.48 h**（生产网格值，与 result3.xlsx 一致；网格收敛外推 57.47 h，离散不确定度 0.41 min，即 57.47–57.48 h） |
| 4 | 考虑半径收缩（2.000 → 1.198 cm）：**51.09 h**；实验室坐标写法 52.65 h（+3.1%）；同物性、半径固定 2 cm 需 129.85 h |

**检验（校验器 `pipelines/a/verify.py` 与求解器代码分离）。** 问题 1 的温度场用 Duhamel 叠加求得真解，在 result1.xlsx 温度表的全部 37 800 个单元上与数值解最大相差 2.0×10⁻⁶ °C；常物性 Robin 圆柱贝塞尔级数解对照误差 1.0×10⁻⁵（温度）/ 1.1×10⁻⁵（水分）。用不受参照偏置影响的三网格估计量，问题 1、2 的空间观测阶为 1.99–2.00，问题 3、4 的烘干终点量为 1.65–1.91。在结果文件的完整 1 s 输出网格上逐格评估离散误差：温度无一单元超过四位小数的半个末位（5×10⁻⁵），水分仅 42 个（问题 1，t ≤ 42 s）与 29 个（问题 2，t ≤ 29 s）表面单元超过。离散水分平衡（常物性下还有能量平衡）是半离散系统的精确线性不变量（残差 ~10⁻¹⁵），由输出样本独立重算的通量积分残差 ~10⁻⁵；极值原理与径向单调性全程成立；更严格容差、Radau 与限制最大步长的解相差 ≤ 4×10⁻⁹；独立编写的二维轴对称程序在端面绝热时与一维解相差 6×10⁻⁹，端部效应对烘干时间的影响 −0.004%；问题 2 与问题 3 的解在共有的 181 个 60 s 整点上逐位相同。灵敏度（烘干时间弹性）：烘房平台温度 −1.60，收缩幅度 −1.13，扩散系数前因子 −0.89，传质系数 −0.11，换热系数 ≈ 0，烘房湿度 +0.02。

**局限（已量化的偏差方向）。**

- **水分守恒的写法**：主模型的干基 Fick 形式在“固定体积 + 干物质守恒”下就是守恒律；若把题给 ρ(C) 读作真实湿密度而采用 ρ_s 加权的守恒型写法，烘干时间为 46.72 h（−18.7%）。这是除判据表述外最大的单项解释不确定性。
- **判据的表述**：按“各处低于 0.15”需 57.48 h，按体积平均只需 36.05 h（−37.3%）。
- **蒸发潜热未耦合**：题给参数体系不含潜热与湿球反馈（直接耦合在题给传质律下不适定）。界定分析表明真实烘干时间很可能比主结果长 17%–26%。
- **收缩数据的自洽性**：题给 R(t) 与题给 ρ(C) 在干物质守恒下相差 13.4%（由 ρ(C) 反推的末半径 1.287 cm vs 附件 2 的 1.198 cm）；本文以附件 2 的几何为准，ρ(C) 仅用于能量方程的 ρc_p。
- **四位小数的适用范围**：除 result1.xlsx 的 42 个、result2.xlsx 的 29 个表面单元（干燥最初数十秒）外，所有交付数值的四位小数都有意义；上述单元的第四位小数受离散误差影响（量级 10⁻⁴）。
- 其余：h、h_m 全程恒定；D 在 C → 0 的外推缺乏数据支撑；14400 s 之后的烘房条件为平台外推（三种取法相差 ≤ 0.53%）；轴向收缩、各向异性与批次差异未建模。
